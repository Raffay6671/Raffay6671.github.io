# Raffay Arshad — Portfolio

Personal portfolio website for **Raffay Arshad**, Full Stack Engineer.

Static single-page site built with plain HTML, CSS, and vanilla JavaScript — no build step, no dependencies to install.

## Run locally

Open `index.html` in a browser, or serve it (recommended, so the resume download and relative paths work):

```bash
# Python 3
python -m http.server 8000
# then open http://localhost:8000
```

## Structure

- `index.html` — all page content (hero, about, experience, projects, skills, certifications, publications, GitHub activity, contact)
- `styles.css` — all styling (light/dark theme)
- `images/` — profile photo (`Raffay.jpg`) and certification badges
- `Resume/` — downloadable resume PDF

## Deploy

Hosted via GitHub Pages — push to a repo named `Raffay6671.github.io` and enable Pages on the `main` branch.
